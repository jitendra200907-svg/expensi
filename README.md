# Expensi

A lightweight INR expense tracker for Jitu. It works offline as a Progressive Web App and stores expenses and budget settings in the browser.

## Run locally

Serve this folder over HTTP or HTTPS, then open `main.html` in a browser. PWA installation and payment-app sharing require HTTP/HTTPS; opening the file directly still supports the tracker and receipt text import.

## Features

- Add, filter, and delete expenses
- Set a saved monthly budget in INR
- View daily, weekly, or monthly spending charts
- Import copied payment receipt text and detect merchant and amount
- Receive shared receipt text when installed as a PWA
- Offline app shell with local browser storage
